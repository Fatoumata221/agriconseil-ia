# EXEMPLE DE FORMAT — CE N'EST PAS UNE FICHE OFFICIELLE

> Ce fichier montre seulement comment présenter une fiche technique.
> Son nom commence par « _ » : il est **ignoré** par la recherche de l'assistant.
> Il ne contient aucune information agronomique et n'est attribué à aucun organisme.

## Comment ajouter une vraie fiche

1. Récupérez une fiche technique publiée (ISRA, ANCAR, service départemental de l'agriculture…),
   en respectant ses conditions de diffusion.
2. Copiez son texte dans un fichier `.md` ou `.txt` de ce dossier `docs/`, avec un nom clair,
   par exemple `ISRA-arachide-semis-2024.md` : ce nom de fichier sera affiché comme source.
3. En tête du fichier, indiquez le titre exact, l'organisme, l'année et le lien d'origine.
4. Séparez les parties par des lignes vides : chaque paragraphe sert de passage pour la recherche.
5. Aucun redémarrage n'est nécessaire : l'index est reconstruit dès qu'un fichier change.

## Modèle à copier

```
# <Titre exact de la fiche>
Source : <organisme>, <année>, <lien ou référence>

## <Partie 1, par exemple « Préparation du sol »>
<Texte de la fiche>

## <Partie 2>
<Texte de la fiche>
```
